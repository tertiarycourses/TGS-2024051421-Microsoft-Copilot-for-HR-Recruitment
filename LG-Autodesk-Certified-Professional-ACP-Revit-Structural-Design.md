# Learner Guide - Autodesk Certified Professional (ACP) Revit Structural Design

> Course: Autodesk Certified Professional (ACP) for Revit Structural Design  
> Course Code: TGS-2023039179  
> Registration: https://www.tertiarycourses.com.sg/wsq-autodesk-certified-professional-acp-for-revit-structural-design.html

This learner guide supports a practical Autodesk Revit Structural Design course aligned to Autodesk Certified Professional preparation. The labs focus on structural project setup, core structural elements, framing, foundations, reinforcement, content management, documentation, collaboration, model review, and final output.

## Learning Outcomes

By the end of the labs, you should be able to:

- Set up a Revit structural project from a linked architectural model.
- Coordinate levels, grids, copy/monitor workflows, and shared coordinates.
- Model structural columns, walls, floors, beams, braces, framing systems, and connections.
- Model foundations, slabs, and selected structural access elements.
- Place and document reinforcement using rebar and area reinforcement tools.
- Manage structural families, types, materials, object styles, schedules, and annotation.
- Create callouts, detail views, sheets, revisions, and exported PDFs.
- Use phases, design options, worksharing concepts, warnings review, interference checks, audit, compact, purge, standards transfer, and export settings.
- Complete common Revit Structural Design ACP tasks under timed conditions.

## Recommended Setup

1. Use Autodesk Revit on a classroom computer or licensed workstation.
2. Create a working folder named `TGS-2023039179-Revit-Structural-Labs`.
3. Save a separate Revit file for each lab milestone.
4. Keep exported PDFs and schedule files in `08-Final-Deliverables`.
5. Save incremental versions before reinforcement, worksharing, purge, audit, compact, or coordination checks.

## Lab 1 - Project Setup, Links, Copy/Monitor, Grids, and Levels

### Objectives

- Start a Revit structural project.
- Link architectural references.
- Coordinate levels and grids.
- Review site and shared coordinate concepts.

### Procedure

1. Create the course lab folder.
2. Start Revit and create a project from a structural template.
3. Save the project as the Lab 1 file.
4. Link the architectural model.
5. Use the positioning method assigned by your trainer.
6. Pin the linked model.
7. Copy/Monitor levels and grids if assigned.
8. Create additional structural grids and levels.
9. Rename grids and levels clearly.
10. Create structural plan views for major levels.
11. Create a coordination 3D view.
12. Review site file and shared coordinate concepts.
13. Save the project.

### Checkpoint

The project should have a linked architecture model, coordinated grids and levels, and structural views ready for modeling.

### Review

- Why is linked model positioning important?
- What does Copy/Monitor help control?
- When are shared coordinates important?

## Lab 2 - Structural Columns, Walls, Floors, and Materials

### Objectives

- Model primary structural elements.
- Use constraints and levels correctly.
- Apply structural materials.
- Review 3D and analytical display.

### Procedure

1. Open the Lab 1 project and save a Lab 2 copy.
2. Place structural columns at grid intersections.
3. Set base and top constraints.
4. Create structural walls.
5. Create structural floors or slabs.
6. Edit boundaries where required.
7. Duplicate types before changing sizes or materials.
8. Assign concrete, steel, or assigned materials.
9. Review the model in 3D.
10. Turn on analytical model display if assigned.
11. Correct alignment or constraint issues.
12. Save the project.

### Checkpoint

Structural elements should align with grids and levels and use clear materials and types.

### Review

- Why are base and top constraints important?
- Why duplicate types before editing?
- What does the analytical model show?

## Lab 3 - Structural Framing, Beams, Bracing, and Connections

### Objectives

- Add beams, secondary framing, and bracing.
- Create framing views and sections.
- Review joins and connections.
- Tag framing elements.

### Procedure

1. Open the Lab 2 project and save a Lab 3 copy.
2. Open a framing plan.
3. Load framing families if required.
4. Place beams between columns.
5. Add secondary beams or joists.
6. Create a beam system if assigned.
7. Add braces in elevation or 3D view.
8. Review cutbacks and joins.
9. Add structural connections if available and assigned.
10. Confirm materials.
11. Create a framing elevation or section.
12. Tag selected framing members.
13. Save the project.

### Checkpoint

Framing should be readable in plan, section, and 3D, with clear member types and tags.

### Review

- What views are useful for framing work?
- When should beam systems be used?
- What should be checked around connections?

## Lab 4 - Foundations, Stairs, Selection Sets, and Model Organization

### Objectives

- Model foundation elements.
- Add assigned access elements.
- Create selection sets.
- Review model organization.

### Procedure

1. Open the Lab 3 project and save a Lab 4 copy.
2. Open the foundation plan.
3. Place isolated footings below columns.
4. Place wall foundations below walls.
5. Create a foundation slab if assigned.
6. Adjust depths and offsets.
7. Review alignment in section and 3D.
8. Add stairs or access elements if assigned.
9. Create selection sets for columns, framing, and foundations.
10. Use temporary hide/isolate to review sets.
11. Update materials where needed.
12. Save the project.

### Checkpoint

Foundations should align with structural elements, and selection sets should support efficient review.

### Review

- What types of foundations did you place?
- How do offsets affect foundation placement?
- Why are selection sets useful?

## Lab 5 - Reinforcement, Rebar, Area Reinforcement, and Detailing

### Objectives

- Configure rebar cover.
- Place rebar and area reinforcement.
- Tag reinforcement.
- Create reinforcement detail views.

### Procedure

1. Open the Lab 4 project and save a Lab 5 copy.
2. Select a concrete structural element.
3. Review rebar cover settings.
4. Create a section view.
5. Place shape-driven rebar.
6. Adjust layout rules.
7. Constrain rebar to cover references if assigned.
8. Place stirrups, main bars, or distribution bars.
9. Add area reinforcement to a slab or wall if assigned.
10. Review visibility in 3D and section views.
11. Add rebar tags.
12. Create a reinforcement schedule if assigned.
13. Add detail components and notes.
14. Save the project.

### Checkpoint

Reinforcement should be visible, tagged, and understandable in detail views.

### Review

- What does rebar cover control?
- How do layout rules affect rebar placement?
- Why are reinforcement views often separate from general plans?

## Lab 6 - Structural Families, Type Catalogs, Schedules, and Annotation

### Objectives

- Manage structural family types.
- Review type catalog concepts.
- Create structural schedules.
- Add annotation and tags.

### Procedure

1. Open the Lab 5 project and save a Lab 6 copy.
2. Select a structural family.
3. Review family category and type properties.
4. Duplicate a type before changing dimensions or materials.
5. Rename the duplicate type clearly.
6. Review Object Styles for structural categories.
7. Edit simple family content if assigned.
8. Review type catalog concepts if a sample is provided.
9. Create a structural column schedule.
10. Create a framing or foundation schedule.
11. Add fields such as type, level, length, material, mark, and comments.
12. Sort and group schedule data.
13. Add structural tags.
14. Save the project.

### Checkpoint

Schedules should update from model data, and edited types should be clear enough for review.

### Review

- What is a family category?
- Why are type names important?
- Which schedule fields are useful for structural review?

## Lab 8 - Collaboration, Interference Checks, Export, and Certification Review

### Objectives

- Practice collaboration and project management tools.
- Review warnings and interference.
- Use model cleanup tools carefully.
- Export final deliverables and complete timed practice.

### Procedure

1. Open the Lab 7 project and save a Lab 8 copy.
2. Review phases and create a phase filter if assigned.
3. Create a design option for alternate framing or foundations if assigned.
4. Review worksharing concepts.
5. Review model warnings.
6. Resolve assigned simple warnings.
7. Run an interference check with the linked model.
8. Record coordination issues.
9. Create a coordination 3D view.
10. Use Audit and Compact only on a safe practice copy.
11. Use Purge Unused only after approval from your trainer.
12. Transfer project standards in a controlled practice file if assigned.
13. Configure export and print settings.
14. Export selected sheets to PDF.
15. Export DWG, IFC, or schedules if assigned.
16. Complete a timed challenge covering link setup, grids, columns, framing, foundation, schedule, sheet, and export.
17. Save final deliverables.

### Checkpoint

You should be ready to perform core Revit Structural Design workflows without step-by-step prompts.

### Review

- What should be checked before export?
- Why should purge and audit be used carefully?
- Which structural tasks require more certification practice?
