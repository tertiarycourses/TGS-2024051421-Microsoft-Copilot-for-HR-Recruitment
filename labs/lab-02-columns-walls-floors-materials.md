# Lab 2 - Structural Columns, Walls, Floors, and Materials

## Objectives

- Place structural columns, walls, and floors.
- Use levels, grids, and constraints correctly.
- Assign and review structural materials.
- Review basic analytical model awareness.

## Scenario

The structural layout begins with vertical and horizontal load-bearing elements. You will create core structural elements and ensure they are constrained and documented correctly.

## Steps

1. Open the Lab 1 project.
2. Save a copy as `TGS-2023039179-Lab02-Structural-Elements-YourName.rvt`.
3. Open a structural plan view.
4. Place structural columns at grid intersections.
5. Set column base and top constraints.
6. Use copy or array tools to place repeated columns.
7. Create structural walls along assigned core or perimeter lines.
8. Set wall base and top constraints.
9. Create structural floors or slabs on assigned levels.
10. Edit floor boundaries where required.
11. Assign materials such as concrete or steel.
12. Duplicate types before modifying dimensions or materials.
13. Review a 3D view for element alignment.
14. Turn on analytical model display if assigned.
15. Correct obvious offsets or constraint problems.
16. Save the project.

## Deliverables

- Structural columns
- Structural walls
- Structural floors or slabs
- Materials assigned
- 3D review view

## Checkpoint

The structural elements should align with grids and levels and should use clear structural types and materials.
