# Revit Structural Design Lab Guide

This folder contains practical labs for TGS-2023039179 - Autodesk Certified Professional (ACP) for Revit Structural Design.

## Lab Sequence

| Lab | File | Outcome |
| --- | --- | --- |
| 1 | [Project Setup, Links, Copy/Monitor, Grids, and Levels](lab-01-project-setup-links-grids-levels.md) | A structural Revit project linked to architecture with grids, levels, site setup, and shared coordinate awareness. |
| 2 | [Structural Columns, Walls, Floors, and Materials](lab-02-columns-walls-floors-materials.md) | A structural model with columns, walls, floors, and material assignments. |
| 3 | [Structural Framing, Beams, Bracing, and Connections](lab-03-framing-beams-connections.md) | Framing model with beams, bracing, beam systems, and connection review. |
| 4 | [Foundations, Stairs, Selection Sets, and Model Organization](lab-04-foundations-stairs-selection-sets.md) | Foundations, stairs or access elements, and organized selection sets. |
| 5 | [Reinforcement, Rebar, Area Reinforcement, and Detailing](lab-05-reinforcement-rebar-detailing.md) | Rebar and reinforcement tools practiced with structural detailing views. |
| 6 | [Structural Families, Type Catalogs, Schedules, and Annotation](lab-06-families-types-schedules-annotations.md) | Family and type practice with schedules and annotation support. |
| 7 | [Views, Callouts, Detail Components, Sheets, and Revisions](lab-07-views-callouts-sheets-revisions.md) | Documentation views, details, sheets, and revision workflow. |
| 8 | [Collaboration, Interference Checks, Export, and Certification Review](lab-08-collaboration-interference-export-cert-review.md) | Collaboration tools, model checks, exports, and timed certification-style practice. |
