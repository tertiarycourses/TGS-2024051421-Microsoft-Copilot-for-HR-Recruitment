# Lab 6 - Structural Families, Type Catalogs, Schedules, and Annotation

## Objectives

- Manage family categories and types.
- Edit or create simple structural family content.
- Understand type catalog use.
- Create structural schedules and annotation families.

## Scenario

Structural projects rely on controlled families, types, schedules, materials, and annotation standards. You will review and customize content safely.

## Steps

1. Open the Lab 5 project.
2. Save a copy as `TGS-2023039179-Lab06-Families-Schedules-YourName.rvt`.
3. Select a structural column, framing, or foundation family.
4. Review its family category and type properties.
5. Duplicate a type before changing dimensions or materials.
6. Rename the duplicated type clearly.
7. Open Object Styles and review structural category settings.
8. Edit a simple family or create a small annotation family if assigned.
9. Review type catalog concepts if your trainer provides a sample.
10. Create a structural column schedule.
11. Create a framing schedule or foundation schedule.
12. Add fields such as type, level, length, material, mark, and comments.
13. Sort and group schedule data.
14. Add tags to selected structural elements.
15. Save the project.

## Deliverables

- Duplicated or edited structural type
- Object style review notes
- Structural schedule
- Tagged structural elements
- Optional annotation family

## Checkpoint

Schedules should update from model data, and edited types should be named clearly enough for review.
