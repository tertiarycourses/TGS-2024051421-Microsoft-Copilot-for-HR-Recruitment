# Lab 4 - Foundations, Stairs, Selection Sets, and Model Organization

## Objectives

- Model isolated footings, wall foundations, and foundation slabs.
- Add stairs or access elements if assigned.
- Use selection sets for model management.
- Organize structural elements for review.

## Scenario

The structural model needs foundation elements and a clean organization method for repeated review tasks. You will model foundations and create selection sets for key structural categories.

## Steps

1. Open the Lab 3 project.
2. Save a copy as `TGS-2023039179-Lab04-Foundations-YourName.rvt`.
3. Open the foundation plan.
4. Place isolated footings below structural columns.
5. Place wall foundations below structural walls.
6. Create a foundation slab if assigned.
7. Adjust foundation depths and offsets as instructed.
8. Review foundation alignment in section or 3D view.
9. Add stairs or structural access elements if assigned.
10. Select all columns and save a selection set.
11. Select all framing members and save a selection set.
12. Select foundations and save a selection set.
13. Apply temporary hide/isolate to review each selection set.
14. Add or update materials where needed.
15. Save the project.

## Deliverables

- Foundation elements
- Optional stair or access element
- Selection sets for major structural categories
- Foundation review view

## Checkpoint

Foundations should align with structural elements, and selection sets should make model review faster.
