# Lab 5 - Reinforcement, Rebar, Area Reinforcement, and Detailing

## Objectives

- Configure rebar cover settings.
- Place rebar in structural elements.
- Use area reinforcement where appropriate.
- Create reinforcement tags and detail views.

## Scenario

Reinforced concrete elements require clear reinforcement modeling and documentation. You will place rebar and create views for review.

## Steps

1. Open the Lab 4 project.
2. Save a copy as `TGS-2023039179-Lab05-Reinforcement-YourName.rvt`.
3. Select a concrete beam, wall, floor, or foundation element.
4. Review rebar cover settings.
5. Create a section view through the selected element.
6. Place rebar using shape-driven tools.
7. Adjust layout rules such as fixed number or maximum spacing.
8. Constrain rebar to cover references if required.
9. Place stirrups, main bars, or distribution bars as assigned.
10. Add area reinforcement to a slab or wall if assigned.
11. Review rebar visibility in 3D and section views.
12. Add rebar tags.
13. Create a simple reinforcement schedule if assigned.
14. Add detail components or notes where needed.
15. Save the project.

## Deliverables

- Rebar in at least one structural element
- Area reinforcement if assigned
- Rebar tags
- Reinforcement detail view
- Optional reinforcement schedule

## Checkpoint

Reinforcement should be visible, tagged, and understandable in the selected documentation view.
