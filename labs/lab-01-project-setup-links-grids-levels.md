# Lab 1 - Project Setup, Links, Copy/Monitor, Grids, and Levels

## Objectives

- Create a Revit structural project.
- Link or import an architectural reference.
- Coordinate levels and grids using copy/monitor concepts.
- Create a simple site file or shared coordinate awareness workflow.

## Scenario

You are starting a structural Revit model based on an architectural reference. Before creating structural elements, the project needs coordinated levels, grids, views, and shared positioning rules.

## Steps

1. Create a folder named `TGS-2023039179-Revit-Structural-Labs`.
2. Launch Autodesk Revit.
3. Start a new project from a structural template.
4. Save the file as `TGS-2023039179-Lab01-Setup-YourName.rvt`.
5. Link the architectural model provided by your trainer.
6. Use the assigned positioning method.
7. Pin the linked model.
8. Open an elevation or coordination view.
9. Copy/Monitor levels from the linked architectural model if assigned.
10. Copy/Monitor grids if assigned.
11. Create additional structural grids and levels where required.
12. Rename grids and levels clearly.
13. Create structural plan views for major levels.
14. Create a coordination 3D view.
15. Create or review a site file workflow if your trainer provides site data.
16. Review shared coordinates and project base point behavior.
17. Save the project.

## Deliverables

- Structural Revit project file
- Linked architectural model
- Coordinated levels and grids
- Structural views and coordination view
- Shared coordinate notes

## Checkpoint

The structural project should show the architectural link clearly and include coordinated grids and levels ready for modeling.
