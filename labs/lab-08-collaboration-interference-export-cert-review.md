# Lab 8 - Collaboration, Interference Checks, Export, and Certification Review

## Objectives

- Practice phases, design options, and worksharing concepts.
- Assess warnings and interference issues.
- Use audit, compact, purge, and standards transfer workflows.
- Export deliverables and complete timed certification-style review.

## Scenario

Before final submission, the structural model must be checked, coordinated, cleaned, exported, and reviewed against certification task areas.

## Steps

1. Open the Lab 7 project.
2. Save a copy as `TGS-2023039179-Lab08-Final-Review-YourName.rvt`.
3. Review phases and create a simple phase filter if assigned.
4. Create a design option for an alternate framing or foundation layout if assigned.
5. Review worksharing concepts and worksets if using a practice model.
6. Open Manage Warnings and review unresolved warnings.
7. Resolve simple warnings if instructed.
8. Run an interference check between structural categories and the linked model.
9. Record coordination issues.
10. Create a coordination 3D view.
11. Use Audit and Compact only on a safe practice copy if instructed.
12. Use Purge Unused only after confirming it is safe for the exercise.
13. Transfer project standards in a controlled practice file if assigned.
14. Configure export and print settings.
15. Export selected sheets to PDF.
16. Export DWG, IFC, or schedule files if assigned.
17. Complete a timed challenge covering link setup, grids, columns, framing, foundation, schedule, sheet, and export.
18. Save final deliverables.

## Deliverables

- Final Revit project file
- Coordination and warning review notes
- Interference check results
- Exported PDF sheets
- Optional DWG, IFC, or schedule export
- Timed review notes

## Checkpoint

You should be ready to demonstrate core Revit Structural Design ACP workflows without step-by-step prompts.
