# Tools Reference

## Required Software

- Autodesk Revit
- PDF viewer

## Helpful Free Tools

- Autodesk Viewer for browser-based model review
- DWG TrueView for viewing DWG exports
- Microsoft Excel or LibreOffice Calc for reviewing exported schedules

## Suggested Source Data

Your trainer may provide files. If not, create or request simple training assets:

- Small architectural Revit model
- Structural design brief
- Grid and level layout
- Column, beam, slab, and foundation assumptions
- Rebar or reinforcement detail brief
- Title block family
- Linked model or DWG reference

## Revit Objects Practiced

- Linked architectural models
- Levels, grids, copy/monitor, and shared coordinates
- Structural columns, walls, floors, framing, bracing, and connections
- Foundations, slabs, stairs, and selection sets
- Reinforcement, rebar, cover settings, and area reinforcement
- Structural families, types, type catalogs, materials, and object styles
- Schedules, tags, callouts, detail components, and annotation families
- Sheets, revisions, print settings, and export settings
- Phases, design options, worksets, warnings, interference checks, audit, compact, purge, and standards transfer

## Learner Tips

- Confirm linked model positioning before modeling structural elements.
- Keep grids and levels coordinated with the architectural model.
- Use structural materials consistently for schedules and documentation.
- Check analytical alignment where your trainer requires structural analysis awareness.
- Save incremental versions before reinforcement, worksharing, or major coordination tasks.
- Review warnings before final export.
