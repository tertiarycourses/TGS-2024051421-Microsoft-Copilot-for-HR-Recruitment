# Lab 7 - Views, Callouts, Detail Components, Sheets, and Revisions

## Objectives

- Create and manage structural views.
- Create callouts and detail views.
- Use detail components for documentation.
- Set up sheets and revisions.

## Scenario

The structural model must be documented with clear plans, sections, details, schedules, sheets, and revision information.

## Steps

1. Open the Lab 6 project.
2. Save a copy as `TGS-2023039179-Lab07-Documentation-YourName.rvt`.
3. Duplicate a structural plan view for documentation.
4. Create a framing plan view if needed.
5. Create a foundation plan view if needed.
6. Create section views through major structural elements.
7. Create callout views for foundation, beam, or slab details.
8. Add detail components in a callout or drafting view.
9. Add dimensions, text notes, and structural tags.
10. Create a site plan view if assigned.
11. Customize view templates or visibility settings.
12. Create sheets with title blocks.
13. Place plans, details, and schedules on sheets.
14. Add a revision cloud and revision entry.
15. Export a sheet to PDF.
16. Save the project.

## Deliverables

- Documentation plan views
- Callout or detail views
- Detail components and annotations
- Sheets with title block
- Revision entry
- Exported PDF

## Checkpoint

The sheets should communicate structural information clearly and use consistent view naming, annotations, and revision data.
